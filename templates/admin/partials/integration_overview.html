Integrations overview

Configure how threat intelligence flows in and out of ZIoCHub. Use the tabs above by direction:

  • Import (pull) — MISP and remote TAXII 2.1 clients pull IOCs into the platform.
  • Export (feeds) — Public feed URLs and TAXII server (ZIoCHub as provider).
  • Push IOC — Cortex XDR, Google SecOps, Cisco ESA, HTTP IOC push, MISP push on submit, OpenDXL.
  • Push YARA — Trellix EX/CMS/NX and generic HTTP YARA upload targets.

Live connection status: Feed Pulse on the main app (Pull / Push state). Platform settings (LDAP, Syslog, Tags, Scoring) stay under Settings.
