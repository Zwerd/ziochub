Feeds & TAXII

Control whether the public Feed and TAXII endpoints are available. When disabled, /feed/* and TAXII object endpoints return 503. Use when defense systems pull from MISP only and you do not need ZIoCHub as a feed source.

Uncheck to disable public access to Feed and TAXII (clients will receive 503).

When enabled, each feed URL (plain, Palo Alto, Check Point, STIX, YARA list, ePO, etc.) is built at most once per TTL; repeat clients read from SQLite. Reduces DB load when many systems poll frequently. New IOCs may appear in feeds after up to the TTL delay.

How often cached /feed bodies may be rebuilt from the database. After saving Feeds settings, the cache is cleared once so the new interval applies. Legacy custom TTL values are normalized to the nearest preset when the page loads.

Search display

In Search & Investigate results, the Comment column can be shown RTL when the text is mostly Hebrew or Arabic (e.g. comments from MISP sync). When disabled, comments always use the default direction (LTR).

When enabled, comments with more Hebrew or Arabic letters than Latin are displayed right-to-left.

Tags governance

Maintain a clean tagging taxonomy. When enabled, analysts can only use tags from the Allowed list. Analysts may optionally suggest new tags for admin approval.

When enabled, submission/edit APIs reject tags not in the allowed list.

Suggestions are queued for admin approval and do not become usable until approved.

Tags are normalized to lowercase and deduped on save.
